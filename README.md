# Meesho Shopping Website

A front-end **Meesho-inspired e-commerce website** created using **HTML5 and CSS3**. This project is designed to provide a simple and attractive online shopping interface with product categories, offers, brands, product sections, navigation, and shopping-related features.

## Project Overview

This project is a static e-commerce website inspired by the design and layout of Meesho. It contains a navigation bar with a search section, profile and cart options, product categories, promotional banners, shopping offers, original brands, and product cards.

The website focuses on practicing **HTML structure, CSS styling, positioning, layouts, images, navigation, and hover effects**.

##  Features

*  Home page with e-commerce layout
*  Search bar
*  Shopping cart UI
*  User/account section
*  Product cards and product listings
*  Category/navigation sections
*  Responsive design for different screen sizes
*  Clean and simple UI using HTML & CSS
*  E-commerce-style homepage

##  Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, colors, borders, positioning, and hover effects
* **SVG** – Profile icon
* **Image Assets** – Product, category, brand, and promotional images
